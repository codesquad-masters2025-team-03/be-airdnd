## ⚙️ 기능

#### 1. 카카오 지도 기반 숙소 조회
#### 2. ChatGPT API를 통한 숙소 추천
#### 3. 토스페이 결제 기능
#### 4. 호스트-게스트 채팅 구현

## 🛠️ 기술 스택 (Tech Stack)

### 🔙 Backend
- **Java 21**
- **Spring Boot**
- **MySQL**
- **Redis**
    - Pub/Sub: 실시간 채팅 메시지 브로드캐스팅
    - Key-Value: 예약 관련 캐싱
- **OpenAI (ChatGPT API)**
- **Spring WebSocket** - 실시간 양방향 통신

### 🔚 Infra & Deployment
- **Amazon EC2 (1대)** - 애플리케이션 서버 호스팅
- **Nginx** - 리버스 프록시 및 정적 파일 서빙
- **VPN** - 보안 네트워크 통신 구성
- **GitHub Actions** - CI/CD 자동 배포 파이프라인

### 🖥️ Frontend
- **React**
- **HTML5**
- **CSS3**
